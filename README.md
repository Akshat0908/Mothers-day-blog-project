# Mother's Day Blog

A beautiful and interactive blog dedicated to celebrating motherhood through stories, health tips, and inspiration. Built with React, TypeScript, and Tailwind CSS.

![Mother's Day Blog](https://images.pexels.com/photos/3768914/pexels-photo-3768914.jpeg)

## Features

### Core Features
- 🎯 Dynamic Homepage with Featured Stories Carousel
- 📱 Fully Responsive Design
- 📝 Detailed Article Pages
- 🔍 Real-time Search Functionality
- 🏷️ Category-based Filtering
- 📄 Pagination for Articles
- 💅 Modern and Clean UI

### Interactive Elements
- Smooth Image Hover Effects
- Category Filter Animations
- Dynamic Article Loading
- Related Articles Suggestions
- Social Media Integration

### User Experience
- Fast Page Loading
- Intuitive Navigation
- Clean Typography
- Accessible Design
- Responsive Images

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
```

2. Navigate to the project directory
```bash
cd mothers-day-blog
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npm run dev
```

5. Open your browser and visit `http://localhost:5173`
